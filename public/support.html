Delta help · Chrome 116 or later

Use the learning lab to create a sourced lesson, try two application exercises, ask about saved sources and export a PowerPoint. Captions and AI-generated explanations can contain errors. An exercise-key match is practice evidence, not proof of mastery or an exam score.

Start with a supported source

  1. Open Learning lab and sign in with Google.
  2. Choose an available captioned excerpt. For another video, provide matching timestamped captions when needed; a URL alone does not guarantee a usable source.
  3. Create a lesson, check your reasoning and use source links to review the original video.
  4. Prepare the PowerPoint, then choose its save link. Export your local backup before clearing browser data.

Free AI allowance: each verified account can use up to US$0.50 of estimated AI usage for its lifetime. Individual learning sessions have a separate budget below US$0.10. There is no daily reset, cash balance or automatic top-up. Shared provider limits may pause new AI requests. Saved material is kept when a request fails.

History imports and the Starter Pack

Your account includes ten lifetime imports of distinct YouTube video IDs, shared between the YouTube-account and optional Chrome-history import paths. The default YouTube import reads at most the latest ten visible videos. Sign in on the Delta website to verify the allowance before saving. Re-importing the same video uses no additional import; deletion or reinstallation does not reset it.

Existing saved history, maps, lessons and exports stay available. The import allowance is separate from estimated AI credit. The US$5 one-time Starter Pack candidate adds 100 imports and 20 bounded learning sessions. Checkout is Sandbox-only when enabled: no real money is charged. The account screen shows current availability. Returning from Checkout alone does not grant allowance; choose Check this purchase to verify its status. Do not open another payment while confirmation is pending. A paid lesson uses one session on success and includes up to two distinct follow-up answers. Choose the paid allowance explicitly when free AI credit is used. Paid-result recovery copies are encrypted on the server and retained beyond seven days; see the privacy notice.

Extension installation

A Chrome Web Store listing has not been published for this build. A ZIP is a developer/test package, not a one-click store installation. Do not install an unknown file or change Chrome security settings to bypass an installation warning.

If you are testing a supplied unpacked build, extract its ZIP, open Chrome's extension management page, enable Developer mode and choose Load unpacked for the folder containing manifest.json. Keep that folder in place. Updates to an unpacked build need a reload and a YouTube-page refresh. These developer steps are separate from normal Chrome Web Store installation.

Open Delta from Chrome's extension menu. The learning website handles Google sign-in when requested. Website and extension records are separate. The packaged extension allows the hosted Delta service and explicit localhost development services; an arbitrary custom HTTPS backend is not supported by this build.

If a step stops

  • Google sign-in: allow the website's sign-in popup, select the intended account and use Reconnect if available. Never paste an API key or password into Delta.
  • Source unavailable: use a listed source or matching timestamped captions for an excerpt of up to five minutes. Missing or restricted captions can block a video.
  • AI temporarily unavailable: keep your saved material and try later. Repeated attempts can reserve usage; the service does not promise unlimited retries.
  • Credit unavailable or exhausted: refresh your account credit once. Clearing local storage or reinstalling does not reset the lifetime allowance.
  • PowerPoint: prepare the download again if its link expired. This does not require a new AI lesson. Save a local copy before leaving the page.

Report a problem safely

Contact the Delta operator using the channel that supplied this build. Include the page or feature name, a short description of what you expected, the visible error message, your Chrome version and whether saved work still opens. Crop screenshots to remove account names and private learning content.

The public source repository includes setup and verification notes. A public support mailbox has not yet been configured. Do not post API keys, passwords, identity tokens, browser cookies, personal account details or private local backups to the repository. Store distribution and an operational private support channel remain pending.
