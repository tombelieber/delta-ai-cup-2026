Getting started

One video.
Three small steps.

You can start in your browser, or add the Chrome pilot to keep Delta close to YouTube.

Open the learning lab
  1. 1

    Install the Chrome pilot

    Download and extract the ZIP. In chrome://extensions, enable Developer mode, choose Load unpacked and select the folder containing manifest.json. Keep that folder in place.

    Download Chrome pilot 0.7.3 ↓

    This is a developer pilot, not a Chrome Web Store installation. To update, replace the files in your existing extension folder, click Reload and confirm Delta 0.7.3 on Chrome’s extension card. Then refresh YouTube.

  2. 2

    Open a captioned YouTube video

    Choose a teaching video with readable timestamped captions. Delta works with an excerpt of up to five minutes. Open YouTube’s Show transcript panel if asked.

    Open the SUMIF example (opens in a new tab)
  3. 3

    Choose Learn, then sign in with Google

    Use Learn in Delta and continue on the learning website. Sign in with Google, check the selected source and create your lesson when its matching captions are ready.

    Ten lifetime history imports and US$0.50 estimated AI credit are included per account. History import verifies your allowance on the Delta website; your first import selects up to ten visible videos. Additional imports are not on sale yet. If Learn does not connect, use the browser lab with a prepared source or matching captions.

From watching to trying

Don’t leave it
at “I get it.”

Try two application exercises in new situations. Use a hint when you need one, then follow the source link to revisit the explanation.

Ask a question across your saved sources. Delta brings back the relevant moments, so you can check the context yourself.

Exercises and answer keys are AI-authored. A matched answer is practice evidence, not a mastery or exam-score claim.

Read the privacy notice

Your learning stays in this browser

Saved lessons and attempts are separated by your signed-in account on this device. Website and extension libraries do not sync. Selected captions, questions and context go to Delta’s backend and Gemini when you request AI help. Download a backup or PPTX before clearing browser data.

A small, defined AI allowance

Each verified account gets up to US$0.50 in lifetime estimated AI usage, with a separate session guard below US$0.10. It is not cash and does not reset daily. AI is available only in provider-supported regions and can pause when credit or shared quotas are used up.

A pilot, with a few boundaries.

Some videos have no usable captions. A pasted URL alone does not guarantee a lesson. Captions and AI explanations can contain errors; check the source before relying on them.

This Chrome build uses an unpacked installation. Store installation and the latest extension handoffs are still pending. If you want the verified starting point, use the browser learning lab.
