# Static onboarding source

Public installation entry: https://delta-511903.web.app . The working website is https://delta-assistant-613646062582.us-central1.run.app .

The home page's **Watch the demo** action opens the [qualified product demo](https://www.youtube.com/watch?v=XokomcChqWs). The separate SUMIF teaching example remains an input video, not the product demonstration.

HTML, CSS and Hosting configuration are retained from the locked source. Approved screenshot and media assets are deliberately not redistributed in this source snapshot; the live onboarding site contains the currently published presentation. Missing screenshot files do not affect the main React/Node product builds. This directory has no JavaScript, tracking or authentication bridge.

The Hosting config names the public Delta site. A fork must use its own authorized Firebase target. Do not deploy this target merely to inspect the source. Hosting the static page does not deploy or qualify the backend, sign-in, credit ledger or installed Chrome pilot.
